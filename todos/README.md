# Panel de To-Dos por Fases — NASA Space Apps Challenge

Este directorio organiza las tareas ejecutables del equipo por fases secuenciales. Para evitar cuellos de botella en un hackathon, cada fase tiene **criterios explícitos de salida (Definition of Done)** antes de avanzar a la siguiente.

# Carpeta `anotaciones/` — Cuadernos de Trabajo y Decisiones

Esta carpeta recoge el pensamiento vivo del equipo durante el hackathon: ideas iniciales, acuerdos de reuniones y decisiones de arquitectura técnica, evitando que las conclusiones se pierdan en chats sueltos.

## Índice de cuadernos

| Código | Archivo | Uso principal |
| :--- | :--- | :--- |
| `ANO-01` | [`01_brainstorming_ideas.md`](01_brainstorming_ideas.md) | Registro de propuestas de cada integrante, análisis de pros/contras y votación. |
| `ANO-02` | [`02_bitacora_reuniones.md`](02_bitacora_reuniones.md) | Actas cortas de los puntos de control (*checkpoints*) del equipo. |
| `ANO-03` | [`03_decisiones_arquitectura.md`](03_decisiones_arquitectura.md) | Registro ligero de decisiones técnicas (ADR): qué se decidió y por qué. |
